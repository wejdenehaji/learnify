Qu'est-ce que le développement web ?

Le développement web consiste à créer des sites et des applications accessibles depuis un navigateur. Pour commencer, on utilise principalement HTML pour organiser le contenu et CSS pour définir son apparence.

✦

À retenir
HTML donne une structure au contenu, tandis que CSS s'occupe de la présentation visuelle.

Un petit exemple

Voici un exemple de structure HTML. Le navigateur lit ces éléments et affiche un titre suivi d'un paragraphe.

<h1>Bonjour !</h1>
<p>Bienvenue sur ma page web.</p>

Essayez de repérer le titre et le paragraphe. Dans les prochaines leçons, nous verrons comment ajouter des styles et organiser les éléments.
